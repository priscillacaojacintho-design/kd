# Treino Adaptativo

App de uma página (`index.html`) que monta treinos de academia pelo seu objetivo, troca o plano a cada 3 semanas e recalcula cardio, séries e meta de kcal a partir dos treinos registrados (kcal, minutos, esforço e peso).

Abra `index.html` no navegador. Os dados ficam salvos no navegador (ou na sua conta, quando aberto como artifact do Claude).
